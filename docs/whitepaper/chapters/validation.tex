\chapter{Validation and Robustness Tests}

To mitigate overfitting the bot subjects strategies to distributional checks on shuffled data and forward projections of trade sequences. The tooling lives in \texttt{src/backtest}.

\section{Permutation Testing}
The \texttt{PermutationTester} implements the NeuroTrader methodology by decomposing each bar into overnight gaps and intraday movements, shuffling them independently, and reconstructing synthetic paths. Let $\{G_t\}$ be gaps and $\{I_t\}$ intra-day changes in log space. For each permutation $k$ a synthetic series is rebuilt as
\begin{equation}
\tilde{p}^{(k)}_t = \exp\!\left(\tilde{p}^{(k)}_{t-1} + G_{\pi_k(t)} + I_{\sigma_k(t)}\right).
\end{equation}
Running the strategy backtest on real data yields profit factor $\Pi_{\text{real}}$; the permutation distribution $\{\Pi^{(k)}\}$ defines the empirical p-value
\begin{equation}
\hat{p} = \frac{1 + \#\{k : \Pi^{(k)} \geq \Pi_{\text{real}}\}}{1 + K}.
\end{equation}
Listing~\ref{lst:permute} excerpts the implementation.

\begin{lstlisting}[language=Python,firstnumber=56,label={lst:permute},caption={Permutation loop excerpt}]
for i in range(n_permutations):
    fake_data = self.generate_permutation()
    fake_profit = backtest_func(fake_data, **kwargs)
    if fake_profit >= real_profit:
        better_than_real_count += 1
\end{lstlisting}

\section{Monte Carlo Equity Cones}
The \texttt{MonteCarloOptimizer} bootstraps historical trade returns $\{r_j\}_{j=1}^N$. For each simulation $s$ a length-$T$ path is generated by resampling with replacement:
\begin{equation}
\tilde{E}^{(s)}_t = E_0 \prod_{u=1}^{t} (1 + r^{(s)}_u), \qquad r^{(s)}_u \sim \text{Empirical}(r_1,\dots,r_N).
\end{equation}
Risk-of-ruin and quantile equity outcomes follow directly from the simulated terminal distribution. Listing~\ref{lst:mc} shows the vectorised implementation.

\begin{lstlisting}[language=Python,firstnumber=25,label={lst:mc},caption={Vectorised Monte Carlo simulation}]
random_returns_matrix = np.random.choice(self.trades, size=(num_simulations, num_trades), replace=True)
cum_returns = np.cumprod(1 + random_returns_matrix, axis=1)
equity_curves = self.capital * cum_returns
\end{lstlisting}

\section{Synthetic Data Stress}
Synthetic price paths generated via \texttt{generate\_synthetic\_data} inject controlled volatility and drift regimes to evaluate strategy behaviour under stylised conditions. The generator draws geometric Brownian motion increments with volatility parameter $\sigma_{\text{syn}}$ and optionally overlays jumps. These series feed directly into the permutation and Monte Carlo pipelines to test stability of conclusions when the data generating process deviates from the historical sample.
